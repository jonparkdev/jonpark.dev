# Study plan & digital garden

Agreed 2026-11-12. The garden serves interview prep — never the other way round.

## Goal

- System design interview readiness; **start applying ~Jan 18, 2027**.
- Backbone: the Hello Interview curriculum. Deep dives are allowed but must link back to it.
- DSA + behavioral run on a separate, simpler track (LeetCode list, STAR-stories doc) — not in the garden.
- Fly.io is just the host.

## Daily rhythm (tiered floor)

| Day | Minimum |
|---|---|
| Bad | 15 min of Hello Interview, then 3 sentences from memory (source closed). This counts as a win. |
| Normal | One section, then a note from recall, plus one diagram |
| Curiosity | Follow the rabbit hole; it must end in a note linked to the topic that started it |

Turning a line in `inbox.md` into a seedling counts as the floor.

## Note stages

Promotions come from recall events, not from polish. No skipping stages. Demotion is allowed and encouraged (record why).

| Stage | Meaning | Requirements |
|---|---|---|
| 🌱 Seedling | "I'm thinking about this." | Written from memory with the source closed; linked to its `topic`. |
| 🌿 Budding | "I understand the core idea." | Re-explained from memory **on a different day**, checked against the source and corrected; has an example or sketch; links to at least one other note; open questions listed. |
| 🌳 Evergreen | "I can use this." | Applied in a mock, a design problem, or an explainer; has a "Trade-offs / when NOT to use this" section. Stable, not finished. |

These definitions also live publicly at `/about-stages`.

## Promotions

Diagram → interactive (`.mdx` + React island) → explainer video (YouTube, embedded in the note).

- Triggered only by a felt gap ("I couldn't explain this in a mock" / "I'd get it if I could *see* it").
- Only one in progress at a time; interactive pieces at most about one a month.
- Independent of stage, except that an explainer can count as the 🌳 application event.

## Weekly

- **Gardening session**: 45 min, recurring every Sunday from Nov 22.
  1. Clear `inbox.md`: each line becomes a note or gets deleted.
  2. Re-recall 2–3 seedlings that are at least 3 days old (auto-generated list) to promote them.
  3. Pick next week's mock problem.
- **Solo mock**: timed, unedited recording of a Hello Interview problem. Private, never linked from the site.
- **Human mock**: every 2–3 weeks, starting around week 4. Book the first one now.

## Stack

- Write in **Obsidian**; the vault is `garden/`.
- Draw with the **Excalidraw** plugin, with auto-export SVG to `garden/assets/`.
- Publish via **Obsidian Git**, which auto-pushes to a public GitHub repo. `inbox.md` is gitignored.
- A **GitHub Action** runs `fly deploy`.
- **Astro + MDX + React**: a static build served from a minimal container on **Fly.io**. If Fly fights you, fall back to Cloudflare Pages.

```
jonpark.dev/
  src/            Astro app
  garden/
    notes/        one .md per note (.mdx only once promoted to interactive)
    assets/       exported SVGs, images
    inbox.md      private quick capture (gitignored)
  curriculum.ts   Hello Interview sections + 🐇 Tangents
  fly.toml, Dockerfile
```

Note frontmatter: `stage`, `topic` (required, a key in `curriculum.ts`), `promotions`. Nothing else until it hurts not to have it.
