# Study plan

Agreed 2026-11-12. The garden serves interview prep, never the other way round. For Stage rules and vocabulary see `GLOSSARY.md`; for how the site works see `PRODUCT.md`.

## Goal

- System design interview readiness; **start applying ~Jan 18, 2027**.
- Backbone: the Hello Interview Course. Deep dives are allowed but must link back to it (as 🐇 Tangents).
- DSA + behavioral run on a separate, simpler track (LeetCode list, STAR-stories doc), not in the garden.

## Daily rhythm (tiered floor)

| Day | Minimum |
|---|---|
| Bad | 15 min of Hello Interview, then 3 sentences from memory (source closed). This counts as a win. |
| Normal | One section, then a Note from Recall, plus one Diagram |
| Curiosity | Follow the rabbit hole; it must end in a Note linked to the Topic that started it |

Turning a line in the Inbox (`garden/inbox.md`) into a Seedling counts as the floor.

## Upgrades

Triggered only by a felt gap ("I couldn't explain this in a Mock" / "I'd get it if I could *see* it"). Only one in progress at a time; Interactives at most about one a month.

## Weekly

- **Gardening session**: 45 min, every Sunday from Nov 22.
  1. Clear the Inbox: each line becomes a Note or gets deleted.
  2. Re-recall 2–3 Seedlings that are at least 3 days old (auto-generated list) to promote them.
  3. Pick next week's Mock problem.
- **Solo Mock**: timed, unedited recording of a Hello Interview problem. Private, never linked from the site.
- **Human Mock**: every 2–3 weeks, starting around week 4. Book the first one now.

## Dates

- **Nov 12**: Day 1. First Seedling in `garden/notes/` before any site code.
- **Nov 14–15**: Site MVP weekend (done; see `.scratch/archive/site-mvp/`).
- **Nov 22**: First Gardening session.
- **~Week 4**: First human Mock.
- **~Jan 18, 2027**: Start applying.
