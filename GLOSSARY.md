# jonpark.dev

A public digital garden of system design notes, kept in service of interview prep. The garden follows the study; the study never follows the garden.

## Notes

**Note**:
One idea written up in the garden, belonging to exactly one Topic and sitting at exactly one Stage.
_Avoid_: Post, article, page

**Stage**:
How well a Note is understood: Seedling, Budding, or Evergreen. It changes only through Recall events, never through polish.
_Avoid_: Status, level, maturity

**Seedling** (🌱):
The first Stage: "I'm thinking about this." Written from memory with the source closed.

**Budding** (🌿):
The second Stage: "I understand the core idea." Re-explained from memory on a different day and corrected against the source.

**Evergreen** (🌳):
The third Stage: "I can use this." Applied in a Mock, a design problem, or an Explainer. Stable, not finished.

**Recall**:
Explaining an idea from memory with the source closed. The only thing that justifies moving a Note's Stage.
_Avoid_: Review, revision

**Promotion**:
Moving a Note up a Stage, earned by a Recall event.
_Avoid_: Using "promotion" for Upgrades

**Demotion**:
Moving a Note back a Stage, with the reason recorded. Expected, not a failure.

**Upgrade**:
A richer format added to a Note because of a felt gap: Diagram, then Interactive, then Explainer. Independent of Stage.
_Avoid_: Promotion

**Diagram**:
The first Upgrade: an Excalidraw sketch embedded in a Note.

**Interactive**:
An Upgrade that adds a hands-on piece to a Note.

**Explainer**:
An Upgrade that adds a video to a Note. Can count as the application event for Evergreen.

## Curriculum

**Curriculum**:
The Hello Interview syllabus that the garden is organised around, plus Tangents.

**Part**:
An ordered group of Topics, following Hello Interview's grouping. Tangents form the last Part.

**Topic**:
One Hello Interview section, as an entry in the Curriculum. Every Note belongs to exactly one Topic.
_Avoid_: Section, chapter

**Topic index**:
The home page: every Topic that has at least one Note, plus Tangents, in Curriculum order, each listing its Notes with their Stages. Topics without Notes are not shown. It shows what has been learned, not progress through the syllabus.
_Avoid_: Progress map (the retired MVP home page that marked every Topic, untouched ones included)

**Tended**:
A Note is tended when it was last changed. "Recently tended" lists the latest of these.

**Tangent** (🐇):
A Topic that isn't in Hello Interview, reached by following a rabbit hole from a Topic that is.
_Avoid_: Side quest, extra

## Practice

**Inbox**:
Private quick-capture list. Never published. Each line eventually becomes a Note or gets deleted.

**Gardening session**:
The weekly 45-minute session for clearing the Inbox, re-recalling Seedlings, and picking the next Mock.

**Mock**:
A timed attempt at a system design problem. A solo Mock is recorded and private; a human Mock is with another person.
